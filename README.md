### ✈️ SkyTrack — Flight Delay System
**`Spring Boot` `JWT` `PostgreSQL` `React` `Docker`**

Event-driven API that auto-sends passenger alerts on flight delays/cancellations. Full-stack with React frontend.

**Key Engineering:**
- 🔒 JWT + Spring Security — stateless auth, all write endpoints protected
- ⚡ Pessimistic locking — seat race conditions handled at DB level
- 🔄 State machine — invalid transitions rejected at service layer
- ⚛️ `@Transactional` — status + alert rollback atomically on failure
- 📧 Email in try-catch — alert persists even if SMTP is down
- 📖 Swagger UI — full interactive API documentation
